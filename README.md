# Calculadoras Científicas

Aplicativo Android nativo com um conjunto de 8 calculadoras para física, química e conversão de unidades. Desenvolvido em Kotlin com XML Views como projeto de estudo para desenvolvimento mobile.

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=flat&logo=android&logoColor=white)

---

## Funcionalidades

- Tela de Splash com animação de revelação da assinatura.
- Menu principal com grade responsiva de 8 botões.
- Velocidade Média – cálculo com animação de carro.
- Força (2ª Lei de Newton) – cálculo a partir de massa e aceleração.
- Energia Cinética – cálculo com animação de corredor.
- Conversões de temperatura – Fahrenheit ↔ Celsius (ambos os sentidos).
- Volume do Paralelepípedo – com navegação por teclado entre campos.
- Equação de Torricelli – resolve a velocidade final com raiz quadrada.
- Fórmula da Diluição (C₁V₁ = C₂V₂) – identifica e resolve automaticamente a variável em branco.

## Tecnologias

- Kotlin
- ConstraintLayout para layouts responsivos
- Material Design Components (TextInputLayout)
- Android Animation API (ObjectAnimator, AnimatorSet)
- Suporte a edge-to-edge com WindowInsetsCompat
